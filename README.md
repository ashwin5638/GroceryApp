# Grocery App 🛒

Live Demo: https://grocery-app-frontend-nine.vercel.app/

A full-stack **online grocery ordering application** built with a modern frontend and a scalable backend architecture.


A **production-style grocery platform** where users can browse products and place orders, backed by a Node.js API and MongoDB database. Built with scalability, clean separation of concerns, and deployment readiness in mind.

---

## 🧩 Tech Stack

### Frontend
- **React.js**
- **JavaScript (ES6+)**
- **HTML5 / CSS3**
- **Vercel** (deployment)

### Backend
- **Node.js**
- **Express.js**
- **MongoDB** (NoSQL database)
- **Mongoose** (ODM)

---

## ✨ Features

### User Side
- 🛍️ Browse grocery products  
- 📱 Fully responsive UI  
- ⚡ Fast client-side rendering  

### Backend
- 📦 RESTful APIs for products 
- 🗃️ MongoDB data persistence  
- 🚀 Ready for auth, cart
